; Mantle -- Data\NVSE\Plugins\Scripts\ln_Mantle.txt
;
; Requires JIP LN NVSE (the ray casts) and JohnnyGuitar NVSE.
;
; The plugin answers one question -- is the player walking into something --
; because that has to be asked every frame and can only be answered honestly
; from inside the movement solve. Everything after that is here, because JIP's
; ray casts are script functions and none of this is per-frame work.

; The lift animations, made for this mod. Each is cloned onto its own throwaway
; form and repointed, so no esp is needed and no animation has to be swapped at
; the moment it is wanted -- the choice is which form to hand to ForcePlayIdle.
;
; Folder names carry the author's spaces on purpose, so a fresh export can be
; dropped straight in. If an animation ever silently fails to play, that is the
; first thing to suspect.
ref rMantleRegular = TempCloneForm LooseCallForHelpA
SetIdleAnimPath rMantleRegular "characters\_male\idleanims\Mantle\Regular Weapon\SpecialIdle_ClimbUp.kf"
player.AuxVarSetRef "*_Mantle_IdleR" rMantleRegular

ref rMantleHeavy = TempCloneForm LooseCallForHelpA
SetIdleAnimPath rMantleHeavy "characters\_male\idleanims\Mantle\Heavy Weapon\SpecialIdle_ClimbUp.kf"
player.AuxVarSetRef "*_Mantle_IdleH" rMantleHeavy

ref rMantleLow = TempCloneForm LooseCallForHelpA
SetIdleAnimPath rMantleLow "characters\_male\idleanims\Mantle\Low Obstacle\SpecialIdle_ClimbUp.kf"
player.AuxVarSetRef "*_Mantle_IdleL" rMantleLow

; Below this fraction of the player's height an obstacle is stepped over rather
; than climbed, and gets its own animation whatever is in hand. 0 turns that off
; and leaves the two weapon animations.
player.AuxVarSetFlt "*_Mantle_LowMax" 0.35 0

; Climbing without a key press works, and works well -- see STATE.md. It is off
; while the rest is being built, because a trigger that fires on its own makes
; every other bug look like a different bug. Turn it on from the console with:
;   player.AuxVarSetFlt "*_Mantle_Auto" 1 0
player.AuxVarSetFlt "*_Mantle_Auto" 0 0

; Whether Player Physics stands down for the lift. Off hands the player back to
; the engine's own movement for the duration, which also re-arms rooting and
; real fall distance -- see MainLoop.gek, where the trade is written out.
;   player.AuxVarSetFlt "*_Mantle_Yield" 0 0
player.AuxVarSetFlt "*_Mantle_Yield" 1 0

; How long the view is held, in seconds, on its own clock rather than the
; climb's -- a low crate is over in four tenths, and splitting that between a
; look down and a look back reads as a flinch however it is eased. The first
; 45% pulls the view onto the ledge, the rest puts it back. 0 turns it off.
player.AuxVarSetFlt "*_Mantle_CamDur" 0.9 0

; How hard the player is shoved forward as the climb releases, in the units
; PushActorNoRagdoll takes. The climb arrives on top with no velocity of its
; own, since it moved positions rather than pushing; this is what keeps the
; player from stopping dead up there. 0 turns it off.
player.AuxVarSetFlt "*_Mantle_Push" 40 0

; How far down the view may be pulled, in degrees. The true angle to the top of
; a waist-high fence is around sixty, which is a stare at the floor; this is the
; glance that was actually wanted.
player.AuxVarSetFlt "*_Mantle_CamPitchMax" 22 0

; A climb that never finished -- saved during one, or crashed out of one -- would
; otherwise resume on load and move the player, and would leave the looking
; control taken away with nothing running that knows to give it back. Costs
; nothing when there was no climb.
player.AuxVarSetFlt "*_Mantle_Time" 0 0
player.AuxVarSetFlt "*_Mantle_CamTime" 0 0
EnablePlayerControls 0 0 0 0 1 0 0

CallWhilePerSeconds 0.011 (CompileScript "Mantle\MainLoop.gek") ({} => 1 == 1) 4
